# Paper source for Overleaf

[Download the latest packaged paper source](Rudeus_VLSP2026_Paper_Source_20261022.zip).

This archive was packaged on 22 October 2026 from the team's current English
LaTeX draft, **Bridging Structure and Semantics for English-Vietnamese Legal
Document Translation**. It includes the full task name and the blue, clickable
competition URL aligned below the abstract. The source cites 14 research works.
This is a working draft, not a claim of acceptance or publication.

## Open in Overleaf

1. Download the ZIP above without extracting it.
2. On the Overleaf dashboard, choose **New Project > Upload Project**.
3. Upload the ZIP and select `main.tex` as the main document.
4. Compile with pdfLaTeX or XeLaTeX. The locally verified PDF used a XeTeX-based
   compiler; exact pagination may differ between engines or TeX versions.

The archive contains only these five required files:

```text
main.tex
references.bib
acl.sty
acl_natbib.bst
figures/document_bleu_delta.png
```

No model weights, competition source/reference datasets, private predictions,
Qwen layout-reference CSV, credentials, or third-party paper PDFs are included.
The figure is a diagnostic plot from the reported validation comparison, not
a set of private translation texts. The compiled manuscript PDF is not included.
